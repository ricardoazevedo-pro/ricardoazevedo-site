About

I'm an IT Senior Technician with 3 years of production experience, working daily with cloud infrastructure, identity systems, and enterprise endpoint environments. My work spans tenant management, endpoint configuration, and software packaging for deployment via Intune and DTM — environments where precision isn't optional.

That operational background shapes my approach to software: I think about reliability, correctness, and failure modes before writing a single line of code. I'm drawn to systems where getting it wrong has real consequences — where building it right genuinely matters.

I work heavily in PowerShell for automation and scripting, manage both Windows Server and Linux environments, and operate deep in the Azure / Microsoft 365 stack. I also run a small web hosting side business, which keeps me pragmatic about shipping and maintaining real services.

On the development side, I write Python and I'm building towards backend engineering with Kotlin and C# — focused on clean architecture and systems designed to be trusted under pressure.

→ Currently building kotlin-payment-ledger: a production-style financial transactions API — idempotency keys, immutable audit logs, clean architecture.
